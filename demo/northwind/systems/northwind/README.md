# Northwind

An invented company design system: the brand the decklight.io showcase puts its postmortem talk on. Navy, ember and sand, as scales; six roles each theme sets; two themes; three slide templates (cover, statement, card).

It lives in this repository so that the showcase's design-system step is real and reproducible:

```sh
decklight marketplace add demo/northwind
decklight design-system add northwind@northwind talk.html
```
