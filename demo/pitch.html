Your Demo Stops Rotting

Terminal recordings are real PTY output, replayed — never a video

The cast embeds the script that made it. When your CLI changes, one command tells you which slide is now lying.

Safe to Open Someone Else's

A deck travels. That means it arrives on a machine that consented to nothing

  • decklight present serves it read-only under a real CSP header, and prints an ingredients label: what's in this file, what will execute
  • An inventory, never a verdict — no green check mark, because a check mark promises more than any scan can keep
  • --strict strips every script that isn't the known runtime, and the deck still plays — content is HTML, themes are CSS, charts and casts are data

One more, and it's the one most tools never think about. A deck travels — emailed, published, handed over on a USB stick. Which means it lands on a machine belonging to someone who installed nothing and agreed to nothing.

⟨CLICK⟩

So there's a command for playing a deck you did not write. It serves the file read-only over localhost under a real CSP header — an HTTP header, which the document cannot override — and before the first slide renders, it prints an ingredients label. What runtime is in here, does it match the build I have, and every script block it could not account for, by line number.

⟨CLICK⟩

And note what it refuses to print: a verdict. No green check, no safety score. It's a heuristic reading a file someone may have edited, and a green mark would promise more than the mechanism can keep. A list of what will run promises nothing, and is still exactly what you needed.

⟨CLICK⟩

Then strict mode, which is the part I find genuinely elegant: it strips every script that isn't the verified runtime — and the deck still plays. Perfectly. Because content is HTML, themes are CSS, and charts and terminal casts are just data read by trusted code. A well-formed decklight deck carries no third-party JavaScript at all, so there is nothing to lose.

Then Ship It Anywhere

decklight bundle deck.html     # ONE self-contained file — themes, casts, images inlined
decklight pdf    deck.html     # every slide, and it NAMES the ones that overflow
decklight publish deck.html    # → https://you.github.io/talk/ , signed by default

Email the bundle with no instructions attached. It opens in any browser, offline, forever.
