Terminals

Real PTY recordings replayed truthfully, never a video, with the sound of the best mechanical keyboards: thocky, creamy, or clacky.

Live narration

Live text-to-speech, on the fly or cached, presents the deck by itself, perfectly in sync. Captions and pop quiz included. Or record it in your own voice, one beat at a time, and your voice steps the builds the same way.

Reviewed like code

Reviewers comment on slides and git carries it back — no accounts, no service. A comment remembers which slide it was on, so it still finds it after you insert three above. Submitting pushes the review as a branch of its own — one file, never the reviewer’s commits — and the author is told a review is waiting.

Bring your old deck

decklight import talk.pptx brings a PowerPoint, Keynote or Google Slides deck across — bullets, tables, images, speaker notes, charts as data because the numbers were in the file all along, and diagrams as diagrams: SmartArt and the boxes-and-arrows somebody dragged onto a slide both arrive as themed SVG. --theme template derives the deck’s theme from your own template’s palette and fonts.

… and hand a file back

For the people around you who still ask for “the file”: decklight pptx writes a PowerPoint — every slide a picture, the notes real notes, your hidden slides not in it — and decklight pdf prints the presenter’s copy (--notes) or a three-a-page handout with ruled lines (--handout). All four are palette rows too, so you never leave the deck to produce one.

Backup slides, and a stopwatch

data-hidden keeps a slide in the file and out of the talk — it keeps its number, and ?all presents it anyway. The speaker view records how long each slide actually took and writes it back onto the deck, so the next run has a pace to hold.

Publish anywhere

GitHub Pages in one command, signed by default; Netlify and Vercel install as targets. Or --target folder, which writes the whole site into a directory for any host that serves files — a share, a bucket, a box you rsync to.

Everything is text

No binary formats anywhere, so decks diff cleanly in git and agents can read, review, and edit every byte.

The deck remembers

decklight commits as you write. H reads the history back inside the deck — every version with a live preview, what each one changed, and one keystroke to restore it.

Command palette

Press / for a Claude-style palette: every command with its shortcut, type to filter, Enter runs it. Type a number to jump to that slide. Authoring, it also writes every file you can hand over — and publishes, after showing you the URL and waiting for a second press.

You found the lab note. The thocky sound — the default you are hearing — was tuned strike by strike against its own reference board. Each keystroke is a dark contact click bandpassed to 680-1250Hz and rolled off above 1.8kHz, gone within 12 to 17ms: gentle and click-forward, a pop rather than a boom. Under it sits a woody case thump that rings only 5 to 9ms, and here is the detail that sells it as a real board — the thump has two pitches. Most strikes land woody at 130 to 185Hz, and about one in five drops to a deep 58 to 85Hz thock, the way a real board mixes bottom-outs with lighter keys. A second, lighter click follows 35 to 80ms later, which is the key release, and loudness spreads ~4x between a grazed key and a bottomed-out one. Synthesized live in WebAudio. No samples were harmed.

Create a deck

No install needed: npx runs the CLI straight from npm. init scaffolds a self-contained deck plus an agent skill, so Claude Code knows the authoring contract. This terminal is Decklight's own player, replaying a recorded session (press ▶ to run it again).

Or bring the deck you already have

import reads a PowerPoint, Keynote or Google Slides file and writes a decklight deck: bullets, tables, images, speaker notes, and charts as data — the numbers were in the file all along, so a chart arrives as an editable, theme-aware element rather than a picture of one. Diagrams come as diagrams too: SmartArt is read from its data model, not its drawing, and the boxes-and-arrows somebody dragged onto a slide are rebuilt as one themed SVG with the arrows still between the right boxes. --theme template derives the deck’s theme from your own template’s palette and fonts, a hidden slide stays hidden, and anything that cannot cross is named with its slide number. Going the other way, pptx hands a file back to whoever still asks for one — without the slides you were keeping back.

Or borrow from a deck somebody already made

A deck template is somebody’s whole talk, installed from a marketplace. init --from starts a new deck from one — but the more common case is a deck that already exists and wants three slides out of it. In author mode, / → Insert from a template… lists what you have installed and what a registered catalog offers, and renders the slide beside the list, because a template is a deck somebody designed and its headings are the least of what you are choosing between.

Two modes decide what Enter does with the slide under the cursor. Insert takes it, landing after the slide you are on as one undo entry. Apply keeps every word of yours and takes only the shape — layout, backdrop, classes — and previews your slide wearing it before anything is written.

A slide is markup and the rules that shape it, so the CSS a borrowed slide depends on comes with it: .breaks is a stack of bordered cards in the deck it came from, not a bare list in yours. What cannot follow is said before you take it, not after — a cast or an image the slide points at and your deck has not, and a class your deck already means something else by, which keeps your rules rather than quietly restyling slides you never touched.
